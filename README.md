# EthioTractors

Catalogue and quote-request website for an Ethiopian agriculture, construction, and mining machinery importer.

## Features

- Product catalogue with sector filtering (agriculture, construction, mining)
- Quote and contact request forms
- Admin panel with drag-to-reorder product management
- Image upload and management
- cPanel deployment via .cpanel.yml

## Tech

PHP · MySQL · JavaScript · HTML/CSS

## Status

Live production site for a client.
